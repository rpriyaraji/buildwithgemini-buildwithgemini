# My agent: fitness-coach
One-liner: A conversational agent that helps fitness enthusiasts plan workouts and track nutrition with a catalog of exercises and meal plans.

Tool coverage:
- Memory: Remembers user fitness level, dietary restrictions, workout history, and personal goals
- Tools: Looks up exercise routines, logs workout sessions, calculates calorie/macro targets
- Catalog/UI: Exercise catalog and meal plan cards/tables
- Image gen: Generates workout form infographics and meal preparation visuals
- Sandbox: Computes BMI, heart rate training zones, and calorie burn estimates

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for pace/macro calculations, Cloud Trace
